## 전체 설명

```
걷자! - 만보기 미션

매일 걷는 습관을 만들어 드립니다.

📱 주요 기능

✅ 스마트 만보기
• 실시간 걸음 수 자동 측정
• 오늘의 목표 달성률 한눈에 확인
• 칼로리 · 거리 자동 계산

🏆 미션 시스템
• 매일 새로운 미션 도전
• 주간 미션으로 더 큰 보상
• 미션 완료 시 포인트 적립

📅 걸음 기록
• 월간 달력으로 기록 한눈에 보기
• 주간 통계로 나의 활동 패턴 파악
• 90일 걸음 이력 저장

👤 내 정보
• 일일 목표 걸음 수 자유롭게 설정
• 주간 그래프로 성과 시각화
• 누적 포인트 확인

🎯 이런 분께 추천해요
• 운동 습관을 만들고 싶은 분
• 하루 만 보 걷기에 도전하고 싶은 분
• 걷기를 게임처럼 즐기고 싶은 분

걷기만 해도 목표를 달성하는 즐거움,
지금 바로 시작해보세요!
```

| 기기 | 해상도 | 필수 여부 |

3. 기록 탭 - 달력 뷰
